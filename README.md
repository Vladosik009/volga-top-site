## 2. Реализованное решение

Разработан одностраничный сайт-визитка со всеми обязательными разделами:
- **Шапка**: SVG-эмблема команды, название, девиз и адаптивное меню-якоря.
- **О команде**: информация о вузе, направлении подготовки и мотивации участия в хакатоне.
- **Участники**: карточки всех участников с инициалами-аватарами, ролями, навыками и модальным окном с подробной информацией.
- **Навыки команды**: сгруппированный перечень технологий и инструментов.
- **Проекты и идеи**: карточки работ и концепций с описанием и технологическим стеком.
- **Контакты и подвал**: единый контакт капитана команды и ссылка на публичный репозиторий в GitVerse.

**Как пользоваться интерактивными элементами:**
- В разделе **«Участники команды»** нажмите кнопку **«Подробнее»** на любой карточке, чтобы открыть модальное окно с деталями.
- На мобильных экранах доступно выпадающее навигационное меню.

## 3. Технологический стек

- **HTML5** — семантическая разметка страницы.
- **CSS3** — CSS Custom Properties (цветовая палитра), Flexbox, CSS Grid, медиазапросы (`768px`, `1024px`) для адаптивности от `360px` до `1440px+`.
- **JavaScript (ES2023)** — модульная логика динамического рендеринга и интерактива без сторонних UI-фреймворков.
- **Данные в JS** (`src/data/team.js`) — отделение данных о команде, участниках, навыках и проектах от HTML-разметки.
- **Vite 6.2.0** — инструмент локальной разработки и сборки оптимизированной статики (`dist/`).
- **Node.js 24.x / npm 11.x** — среда запуска и управления зависимостями.
- **Docker (Nginx 1.27 Alpine)** — опциональная контейнеризация для запуска в изолированном окружении.

## 4. Архитектура

Приложение построено по принципу разделения данных, представления и логики:
1. **`src/data/team.js`** хранит структурированные данные (общая информация, массив участников, группы навыков, список проектов).
2. **`src/main.js`** читает эти данные, создает безопасные DOM-узлы (`document.createElement` + `textContent`) и заполняет секции страницы в `index.html`.
3. Пользовательские действия (клик по фильтрам проектов, открытие модального окна участника, мобильное меню) обрабатываются слушателями событий в `src/main.js`.
4. **`src/style.css`** задает оформление через CSS-переменные и перестраивает сетки в зависимости от ширины экрана.

## 5. Установка и запуск

### Требования к окружению
- Установленный **Node.js** (версии 18 и выше) и **npm**.
- **Git** (для клонирования репозитория).

### Пошаговый запуск в режиме разработки

1. Клонируйте репозиторий и перейдите в папку проекта:
```bash
git clone <ссылка-на-ваш-репозиторий-gitverse>
cd volga-top-site
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите локальный сервер разработки:
```bash
npm run dev
```

4. Откройте в браузере адрес, который выведет Vite в консоли:
```text
http://localhost:5173
```

### Сборка и проверка production-версии
```bash
npm run build
npm run preview
```
После `npm run preview` сайт откроется по адресу `http://localhost:4173`.

```text
volga-top-site/
├── public/
│   ├── images/              # Фотографии участников
│   └── favicon.svg          # Векторная эмблема команды
├── src/
│   ├── data/
│   │   └── team.js          # Структурированные данные команды, участников, навыков и проектов

├── vite.config.js           # Конфигурация Vite (относительный base для статического хостинга)
├── ai-sessions.zip          # Архив экспортированных диалогов с ИИ (добавить перед сдачей)
└── README.md                # Документация проекта
```

## 9. Дополнительные задания

### Контейнеризация (Docker и Docker Compose)

При наличии установленного **Docker** проект запускается одной командой:
```bash
docker compose up -d --build
```

Либо вручную через `Dockerfile`:
```bash
docker build -t volga-top-site .
docker run -d -p 8080:80 --name volga-top-site volga-top-site
```

После запуска сайт открывается в браузере по адресу:
```text
http://localhost:8080
```

Остановка контейнера:
```bash
docker compose down
```
